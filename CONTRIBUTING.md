# Contributing to Autonomous AI Persona Agent

Thank you for considering contributing to the Autonomous AI Persona project!

## Development Setup

1. JDK 21+ and Maven 3.8+ required.
2. Clone repo and set `GEMINI_API_KEY` environment variable.
3. Run tests using `./mvnw test`.
4. Run locally using `./mvnw spring-boot:run`.

## Pull Request Process

1. Create a feature branch (`git checkout -b feature/my-feature`).
2. Ensure code compiles cleanly without warnings.
3. Add unit tests for new functionality.
4. Submit pull request against `main` branch.
